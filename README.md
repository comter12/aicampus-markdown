'markdown'은 태그 기반의 'markup'을 '단순화'시키기 위해 나온 방식이다.

제목은 다음과 같이 쓴다. (처음: markup. 두 번째: markdown)

줄 바꿈을 해야 효과가 있다.

<h1>제목 테스트</h1>

# 제목 테스트

# 마크다운 문법 살펴보기

## 1. 헤드라인(제목)

'#' 뒤에 '#'을 붙일 때 마다 크기 작아짐.

```
이곳은 백틱 ```시작과 ```끝으로 만든 곳이다.
# 제목1
## 제목2
### 제목3
#### 제목4 : 여기서부터 일반 글자와 비슷하거나 작아짐
##### 제목5
###### 제목6
```
> TIP : '>'은 팁이며, 왼쪽에 강조가 된다.

# 2. 글자 강조 효과

문서를 작성 시 강조 효과 주기.


*한 개는 기울임*
**두 개는 굵은 글씨**
***세 개는 기울고 굵게***
~~물결 두 개는 취소 선~~
`인라인 블럭은 백 틱 하나`

# 3. 목록(list)

내용 또는 순서에 따라 나열할 때 사용.

- `'-'(마이너스)로 목록`으로 표시한다.
- `줄 바꿈`으로 `자동 생성`이 되거나, `직접 '-'를 입력`한다.

 1. `순서 띄어쓰기 후 숫자, 점` 이다.

- [ ] 체크 리스트는 `앞에 [ ]을 작성`한다. 단, `큰 괄호 안에 띄어쓰기` 주의
- [x] 체크 표시는 `공간 안에 'x'`를 작성한다.

- 목록은
  - `들여쓰기로 중첩`이 된다.

 1. 물론
    1. 순서도
    2. 가능하다.

# 4. 링크(link)

`다른 페이지로 이동`하는 연결 도구이다.

```
[보여줄 글자는 큰 괄호](연결주소는 괄호)
단, 주소만 넣을 경우 <연결주소>이다.
```

동일한 저장소는 바로 전송 가능하다. (상대경로로 표시)


# 5. 이미지

본인 혹은 타인이 가진 이미지 모두 볼 수 있다.

```
![설명](이미지주소)
```
